# Villatech Landing Page

Official static website and portfolio for **Villatech** - Custom Software Engineering & AI Solutions Studio.

## Features
- **Next.js 16 (App Router)** & React 19
- **Cyber Noir Aesthetic**: Dark mode theme with Cyber Amber (`#FFB800`) and Cyber Cyan (`#00E5FF`) accents
- **Internationalization (i18n)**: Full Spanish (ES) and English (EN) support with real SVG flag selectors
- **Tailwind CSS v4** & Lucide Icons
- **Responsive & Lightweight**: Optimized static output

## Getting Started

First, install dependencies:
```bash
npm install
```

Run the development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser.

## Build Production Package

```bash
npm run build
```
